# Milestone 5 — Chord sheets manual smoke

- [ ] Drop a `.chordpro` with `{title: ...}` and inline `[C]Hello` into a scanned folder → run Rescan from Settings or Admin → file appears in the chord-sheet list (library icon in the navigator top bar).
- [ ] Tapping it opens the viewer with chords lined up over syllables.
- [ ] +/- buttons shift all chords by a semitone; `±0 / +1 / -1 / …` indicator in the top bar reflects the shift.
- [ ] Refresh button zeros the shift.
- [ ] Positive shifts render sharps (C → C#), negative shifts render flats (C → B → Bb).
- [ ] Deleting the file + rescan removes the row from the list.
- [ ] An unparsable file (no title directive, no inline chords) still appears titled by filename.
