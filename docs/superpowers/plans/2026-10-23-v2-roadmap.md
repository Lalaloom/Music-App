# V2 Roadmap

**Date:** 2026-10-23
**Status:** Draft — subject to redirect per milestone outcome.

**Context:** V1 (M1 + M2 + M3) shipped. The app plays mp3 / mp4, scrolls time-synced lyrics, manages setlists + live queue, and ships a signed-APK sideload with onboarding + entitlement scaffold. V2 opens up the deferred spec items with these two user-provided constraints:

- **No cloud sync** of any kind (Dropbox, OneDrive, Google Drive) — descoped indefinitely.
- **Local-only persistence** continues to be the authoritative model.

That constraint retires §5.9 (sync) and §5.8 (YouTube) permanently. §7.3 and §7.4 lose their reason to exist. Everything else in spec §6 is still on the table.

## V2 scope (ordered by value for a solo gigging musician)

| # | Milestone | Spec | One-line value | Blockers |
|---|-----------|------|----------------|----------|
| M4 | Admin / override screen | §5.12 | Fix problems mid-gig without a laptop | — |
| M5 | Chord sheets (ChordPro) + transposition | §6 v1.1 | Replaces a separate chord-sheet app on stage | Needs test ChordPro files |
| M6 | Bluetooth pedal support | §6 v1.1 | Hands-free page turn / play-pause (sax in hand) | Needs a pedal to validate; keycode mapping is public |
| M7 | Advanced lyric editor with waveform | §6 v2 | Tap-to-time LRC timestamps against the actual audio | — |
| M8 | PDF sheet music display | §6 v1.1 | Scanned charts and horn parts | — |
| M9 | Band mode (local-network sync) | §6 v2 | Two tablets stay in sync on the same wifi | Needs 2+ devices to validate |
| M10 | Shared setlists (file export / import) | §6 v2 | `.setlist.json` share via email / drive link | — |
| M11 | Play Store readiness + billing | §9 | Flip `SideloadEntitlementSource` → `PlayBillingEntitlementSource` | Needs a Play Console account + a Pro feature set to gate; probably sequenced after M5/M6 so the first paid tier is tangible |
| M12 | Marketing site + onboarding video | §6 v2 | Discovery → install → first-gig flow | Pure content; no engineering until M11 is live |

**Explicitly out of V2 scope (per user):** Dropbox sync, OneDrive sync, Google Drive sync, YouTube integration.
**Deferred to V3+:** iOS build, AcoustID fingerprint identification (its licensing cost makes it a monetization-adjacent decision, better evaluated once V2 has revenue), web admin console, band-mode leader election across the open internet.
